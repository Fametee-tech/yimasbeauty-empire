# Yimasbeauty Empire Website — Version 1

A responsive HTML/CSS/JavaScript website for Yimasbeauty Empire.

## Files

- `index.html` — website structure/content
- `style.css` — design and responsive layout
- `script.js` — mobile navigation and WhatsApp booking form
- `assets/yimas-logo.jpeg` — supplied brand logo
- `assets/price-list.jpeg` — supplied price list

## How to run

1. Keep the folder structure unchanged.
2. Open `index.html` in a browser.
3. Test the navigation and booking form.
4. For GitHub Pages, upload the whole project to a repository and enable Pages.

## Important

The booking form opens WhatsApp with the customer's details. It does not create a database record or automatically confirm an appointment.

The current version deliberately does not expose bank account details publicly.
